# Using Grammarly in Google Docs

Get real-time writing suggestions in Google Docs by installing the Grammarly browser extension.

## 1. Install the Extension
1. Visit your browser's extension store (Chrome Web Store, Firefox Add-ons, or Edge Add-ons).
2. Search for **Grammarly**.
3. Click **Add to [Browser Name]**, then click **Add extension** to confirm.

## 2. Sign In
1. Click the **Extensions** icon (the puzzle piece) in your browser toolbar.
2. Select **Grammarly**.
3. Click **Log In** and follow the prompts to authenticate your account.

## 3. Activate in Google Docs
1. Open any file in **Google Docs**.
2. Locate the floating Grammarly status icon in the bottom-right corner.
3. Click the icon to open the sidebar and ensure **Check for suggestions on this domain** is toggled **ON**.

## Troubleshooting

| Symptom | Fix |
| :--- | :--- |
| **Icon missing** | Click the **Extensions** icon, verify **Grammarly** is toggled **ON**, and refresh the page. |
| **Freezing/Lag** | A conflicting extension (often an ad-blocker) is likely interfering. Disable other extensions one by one or test in an **Incognito** window. |

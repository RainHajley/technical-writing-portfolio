== Purpose
This procedure defines the mandatory security steps all remote team members must follow when collecting, storing, and sharing sensitive client information. This ensures compliance with standard privacy laws and protects client confidentiality.

== Scope
This policy applies to all full-time, part-time, and contract employees working in a remote environment who access client records, financial data, or personal identification information.

== Mandatory Security Actions

=== Data Collection and Storage
* *Use Approved Repositories Only:* Store all client files inside the secure corporate cloud storage drive. Never download client files directly to your personal computer's local hard drive or desktop.
* *Apply Access Restrictions:* Set file permissions to *Restricted* immediately upon creating a new folder. Only invite specific team members who directly require access to complete the project.

=== Data Transmission and Sharing
* *Encrypt Shared Links:* When sending a file link via email or team chat, always check the password protection box and set a 7-day link expiration date.
* *Verify Recipient Identity:* Double-check the email address of the recipient before hitting send. Never share sensitive data links in public or group chat channels.

== Compliance Auditing
The operations team conducts random security audits every month to ensure file permissions are set correctly.

WARNING: Violations of this policy will result in a formal review and temporary suspension of data access privileges.
